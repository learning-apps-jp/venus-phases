# 金星の満ち欠け
金星をドラッグして、宇宙からの位置と地球から見た形・大きさを比べる教材。クイズなし。

`dist/index.html` を開くだけで利用できます。外部ライブラリ・通信・アカウント不要。

円軌道（地球1、金星0.723）、地球固定の相対位置モデル。実際には地球も公転します。金星からの太陽方向と地球方向の内積から照明率を算出し、見かけの直径は地球からの距離の逆数で描画。日時・実際の空での傾き・明るさを再現するアプリではありません。

地球固定の模式図であることを最初に説明し、満ち欠けと見かけの大きさを学ぶ授業に使用してください。太陽に近い位置の姿は計算上の形です。望遠鏡や双眼鏡を太陽に向けないでください。

公開URL：https://learning-apps-jp.github.io/venus-phases/

参考：NASA Venus Fact Sheet、NASA Basics of Space Flight Chapter 1、国立天文台「金星が最大光度（2017年2月）」。
