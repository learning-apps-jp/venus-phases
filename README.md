# 金星の満ち欠け
金星をドラッグして、宇宙からの位置・地球から見た形と大きさ・夕方と明け方の見え方を比べる教材。クイズなし。月の満ち欠けアプリを参考に作成。

`dist/index.html` を開くだけで利用できます。外部ライブラリ・通信・アカウント不要。

円軌道（地球1、金星0.723）、地球固定の相対位置モデル。金星上での太陽方向と地球方向の内積から照明率を算出し、見かけの直径は地球からの距離の逆数で描画します。空は模式図。太陽の近くでは実際の観察が難しいことを明示。明るさの極大は再現しません。

参考資料：ユーザー提供「地球09.pdf」、NASA Basics of Space Flight Chapter 1。
